## Recent Work

### [Custos](https://github.com/samsonafolabi/custos) — Automated Loan Reconciliation
*Microfinance lending, Nigeria*

Borrowers get onboarded in under 30 seconds with a virtual account and bank disbursement. Repayments are matched to installments in real time via Nomba webhook integration. Overpayments are stored as credit, underpayments are flagged as disputes automatically.

**Tech:** Node.js · TypeScript · Express · Supabase (Postgres) · Nomba API · Webhook Architecture

---

### [Ally](https://github.com/samsonafolabi/Ally) — AI Agent for Payment Lifecycle Management
*Built for the Prava x Visa Agentic Commerce Hackathon*

Manages the full freelancer/vendor payment lifecycle (quote → PO → invoice → payment) with real authorization checks at every step where money moves. Quotes and invoices are extracted from email with AI, reconciled against each other with confidence scoring, and routed for human approval before any payment executes.

**Tech:** Node.js · TypeScript · Slack (Bolt) · Gmail API · OpenAI · Prava payments API
